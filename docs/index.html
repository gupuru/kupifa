01 — PRINCIPLE

運営は、情報を受け取らない。

キーを預かって「安全に管理します」とは言わない。預かると、漏れる側になるから。
kupifaは中継しない。鍵も文章も、運営の手元には来ない。

03 — GUARANTEES

セキュリティを、宣伝ではなく構造にする。

Bring Your Own Key

キーは、あなたが発行し、あなたが持つ。

Grok と Claude のキーを、各コンソールで自分で取得する。kupifaは預からない。紛失も漏洩も、運営側の事故にならない設計。

Keychain

macOSの金庫へ。

保存先は Keychain。設定画面から端末の外へコピーされることはない。

No relay

中継サーバーなし。

リクエストは選択したプロバイダの公式APIだけ。運営APIを経由しない。

Local history

履歴は端末の中。

指示と結果はパネルのサイドバーに残る。同期用のクラウドは無い。

Zero intake

運営が受け取らないもの

  • APIキー
  • 入力した文章
  • 生成結果
  • 利用履歴
  • どのモデルを使ったか
  • テレメトリ

04 — PRODUCT

速さは、セキュリティと両立する。

メニューバー常駐。⌥ Space でパネル。文章を整える、返事作成、翻訳。Grok と Claude を並べて比較できる。

kupifa ⌥ Space

明日の打ち合わせ、少し遅れそうです。先に資料だけ共有しておきます。

Claude · ローカル実行

明日の打ち合わせに少々遅れる見込みです。恐れ入りますが、先に資料のみ共有いたします。

  • 01

    ホットキー起動

    デフォルト ⌥ Space。Spotlight風のフローティングパネル。

  • 02

    Grok / Claude

    パネル上で切り替え。⌘M で全モデル同時実行、カードで比較。

  • 03

    日英スイッチ

    結果カードで 日 ⇄ EN。未生成の言語はその場で翻訳。

  • 04

    ダブルコピー起動

    ⌘C を続けて2回で、選択テキストを入れてパネルを開く。

05 — START

鍵を発行して、設定に置くだけ。

  1. 1

    キーを自分で取る

    xAI Console と Anthropic Console から発行。kupifaに送る手順は無い。

    キーチェーンへ保存

    メニューバーの ✨ → 設定。キーは macOS Keychain にだけ書き込まれる。

    ⌥ Space

    パネルを開き、整える / 返事 / 翻訳。実行はプロバイダ直通。
